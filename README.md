# filewatch

ローカルファイルを監視して、変更を別の場所へコピー（`sync`）、またはその場で正規表現置換（`replace`）する CLI。

## インストール

```sh
go build -o filewatch .
```

## 使い方

```
filewatch [-c 設定ファイル] [sync|replace]
```

サブコマンドを省略すると `sync` と `replace` を同時に実行する。

`-c` の既定値は `.filewatch`。設定ファイルが無ければ空の設定で起動する。

### sync

監視元の変更を反映先へコピーする。起動時に初回コピーを行い、以降は変更・作成・削除を追従する。
反映先も監視し、反映先のファイル／ディレクトリだけが消された場合は監視元から復元する
（監視元も消えていれば削除の反映なので復元しない）。
対話プロンプトに `{監視元} {反映先}` を入力すると監視を追加できる。ファイル・ディレクトリどちらも可。

```
$ filewatch sync
>> ./src ./dist
added watch: /path/to/src -> /path/to/dist
設定を保存しますか? [y/N]: y
saved: .filewatch
```

### replace

監視対象（ファイルまたはディレクトリ）が書き換わるたびに、sed の置換をその場で適用する。
対話プロンプトに `{監視対象} {sed置換}` を入力すると追加できる。

```
$ filewatch replace
>> ./docs s/foo/bar/g
added replace: /path/to/docs s/foo/bar/g
設定を保存しますか? [y/N]: y
```

置換は sed の `s` コマンド形式 `s/{パターン}/{置換}/{フラグ}`。

- 区切り文字は任意（`s|a/b|x|g`）。`\/` でエスケープもできる。
- フラグは `g`（行内のすべて。無い場合は各行の最初の1件）と `i`（大文字小文字を無視）。
- パターンは Go の `regexp` 構文。置換側では `\1` の後方参照と `&`（マッチ全体）が使える。
- sed と同じく行単位で適用する。
- 置換結果が元と同じ場合は書き戻さないので、自身の書き込みによる無限ループは起きない。
- `|` などシェルの特殊文字を含む式は `'...'` で囲む（対話入力・設定ファイルとも解釈される）。
- 適用されるのは起動後に書き込まれたときなので、既存の内容は対象ファイルを保存し直すと置換される。

### sync と replace の組み合わせ

replace の監視対象が sync の反映先と重なる場合、コピー時にバッファ上で置換してから書き出す。
コピー → 書き戻しの二重書き込みにならず、未置換の中間状態もできない。コピー元は書き換えない。

```
sync ./src ./dist
replace ./dist 's|assets/|/images/|g'
```

反映先がまだ存在しない場合もルールは登録されるので、初回コピーから置換が効く
（この場合、反映先そのものへの外部からの書き込みは監視しない）。

### サブコマンドなし

設定ファイルの `sync` と `replace` を両方起動する。対話入力は設定ファイルと同じく種別を前置する。

```
$ filewatch
>> sync ./src ./dist
>> replace ./docs s/foo/bar/g
```

## 設定ファイル

```
# sync    {監視元}   {反映先}
# replace {監視対象} {sed置換}
sync ./src ./dist
replace ./docs s/foo/bar/g
```

対話入力と同じ形式に種別を前置しただけの行形式。`#` 始まりと空行は無視する。
空白区切り。空白を含むパスや置換式は `'...'` / `"..."` で囲む。
`sync` / `replace` の各行は、対応するサブコマンド（とサブコマンドなし）で使われる。

## 挙動メモ

- 書き込みは一時ファイル + `rename` のアトミック更新。一時ファイルは `rename` が同一ファイルシステム内で済むよう、書き込み先と同じディレクトリに作る。
- 置換は行単位なので、4MB を超えるファイルは全体をメモリに載せず、一時ファイルへ1行ずつ流しながら処理する。差分の有無も流しながら判定し、差分が無ければ書き戻さない。
- 連続する Write イベントは 120ms まとめて 1 回に反映する。
- 監視元と反映先を入れ子にすることはできない（どちらの向きもコピーの無限ループになるため）。
- 終了は Ctrl+C。
